# Jobs Street Croatia — original worker image collection

Created on 17 October 2026 using the built-in image generation tool.

This collection contains **17 new role illustrations and three new wide site images**. Each generation uses a different adult Filipino subject profile and a distinct task, working environment, composition and lighting treatment. They are illustrative scenes, not photographs of named employers or actual applicants.

## Assets and prompts

- Website-ready WebP files: `public/images/street-v2/`.
- Selected generated PNG originals: `design/images/street-v2/`.
- Exact final prompt set, including individual identities and scene briefs: `docs/STREET_IMAGE_PROMPTS_V2.json`.
- Generation mode: built-in imagegen. No API-key CLI fallback was used.

The 17 role filenames match their job slugs. The three full-width photographs are `hero-career`, `hero-skills` and `hero-future`.

Images are compressed and responsively served through Next Image. The logo and social icons retain the existing brand assets. The organization marks have been removed from this website. The new image collection belongs to this separate Jobs Street Croatia project.

## Content migration

The catalog image refresh matches a role's known ID, slug and previous bundled image path. It changes only the image and alternative description, preserving other job fields, staff-uploaded photographs, applications and private documents.
